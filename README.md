**Nama:** Kosmas Anyeq Beraan  
**NIM:** 2418057

## Deskripsi Proyek
Proyek ini merupakan tugas Data Visualization menggunakan Python dan Google Colab. Dataset yang digunakan adalah Smart Farming Crop Yield 2024 untuk menganalisis data pertanian melalui berbagai grafik.

## Informasi Dataset
- Jumlah data: 500 baris
- Jumlah kolom: 22
- Format dataset: CSV
- Dataset sudah melalui proses data cleansing.

## Tahapan Pengerjaan
1. Import library Python
2. Membaca dan memahami dataset
3. Melakukan eksplorasi data
4. Membuat visualisasi data
5. Menganalisis hasil grafik
6. Menyusun kesimpulan

## Tools
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Hasil
Visualisasi digunakan untuk memahami distribusi jenis tanaman, hasil panen, kondisi lingkungan pertanian, serta hubungan antarvariabel pada dataset Smart Farming.
